# v0.2.1

Date: 2026-05-16
Module: `github.com/hunydev/g729`
Release tag: `v0.2.1`

## Summary

`v0.2.1` is a patch release for operational tooling and release-facing
validation around the existing `G729/8000 annexb=no` scope. It does not change
encoder or decoder codec behavior, and it does not add Annex B SID/CNG/DTX,
G.729.1, G.729D, or G.729E support.

The release strengthens RTP and realtime smoke evidence by adding
machine-readable reports and Pion RTP generated packet fixtures.

## Changes Since v0.2.0

- Added `cmd/g729rtpcheck -json` for CI/release artifacts.
- Extended `cmd/g729rtpcheck` reports with stream, marker, padding, extension,
  and CSRC counters.
- Added `cmd/g729loadtest -json` with nanosecond duration fields and
  microsecond processing/wake-late summaries.
- Added Pion RTP generated packet fixtures for `cmd/g729rtpcheck`.
- Expanded RTP edge-case tests for `ptime=20`, multi-SSRC streams,
  payload-type skip behavior, RTP marker/padding/extension/CSRC counters,
  strict timestamp discontinuity, malformed padding, malformed extension, and
  2-byte Annex B SID/CNG rejection.
- Updated operational, clean-room, provenance, and third-party documentation to
  make clear that Pion RTP is a non-runtime generic RTP test dependency, not a
  G.729 codec implementation.

## Claims

The project claims are unchanged from `v0.2.0`:

- Encoder: independent, quality-gated, not byte-exact to ITU reference code or
  `bcg729`.
- Decoder: strict local decoder matches the private ITU Annex A final PCM
  oracle sample-for-sample in the current verifier run (`740800/740800`).
- Scope: G.729 Annex A, RTP payload type 18, `ptime=10` and `ptime=20`,
  `annexb=no`.
- Annex B: not supported; 2-byte SID/CNG frames are explicitly rejected.
- Not supported: G.729.1, G.729D, or G.729E.
- Certification: no ITU certification, endorsement, or encoder byte-exact
  conformance claim is made.
