# v0.1.0-rc1 — pre-tag verification checklist

This is the binding pre-tag verification checklist for
`v0.1.0-rc1`. All commands must be run; results recorded in
[v0.1.0-rc1-verification-log.md](v0.1.0-rc1-verification-log.md).

The tag is **only** placed by a human-driven action after every
gate below is GREEN.

---

## §4. Tag command

After all gates above are GREEN, the tag step is:

```sh
git tag -a v0.1.0-rc1 -m "G.729A-compatible 8 kbps pure-Go codec, first public RC"
```

Tag push is a separate human-driven action and is **not** part of
the Phase 4 closure. The codec author / maintainer pushes the tag
after reviewing the verification log.

---

## §5. Out of scope for this checklist

The checklist verifies release-readiness for v0.1.0-rc1 under the
spec-compliance binding criterion declared in Phase 3-final closure.
The following are explicitly **not** part of this checklist:

- ITU byte-exact conformance verification (not claimed in v0.1.0)
- Annex B / G.729.1 / G.729D / G.729E conformance (not implemented)
- Cross-codec interoperability with specific G.729 implementations
- Production RTP / SIP / MRCP integration testing (caller-side)
- Performance regression vs prior tagged versions (no prior tag exists)
