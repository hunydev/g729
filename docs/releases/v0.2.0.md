# v0.2.0

Date: 2026-05-16
Module: `github.com/hunydev/g729`
Release tag: `v0.2.0`

## Summary

`v0.2.0` is an operational-hardening release for the existing
`G729/8000 annexb=no` product scope. It does not add G.729.1, G.729D, G.729E,
or Annex B SID/CNG/DTX support.

The release promotes `v0.2.0-rc1` after additional default, vet, race,
black-box quality, RTP, and realtime load-test gates. The main runtime change
is an explicit boundary for unsupported Annex B payloads: 2-byte RTP SID/CNG
frames are rejected with `ErrUnsupportedAnnexB`.

## Changes Since v0.1.2

- Added exported sentinel `ErrUnsupportedAnnexB`.
- Updated `DecodeFrame`, `DecodeFrameEnhanced`, and
  `DecodeFramePostfilterBlend` to reject 2-byte Annex B SID/CNG frame shapes
  before speech-frame decoding.
- Updated `cmd/g729rtpcheck` to surface the same Annex B sentinel for raw
  payload streams and RTP payload validation.
- Added machine-readable FFmpeg black-box encoder quality report output via
  `G729_FFMPEG_BLACKBOX_REPORT`.
- Added [`../operational-hardening.md`](../operational-hardening.md) to record
  RTP/SDP, SID/CNG rejection, quality gate, and realtime load-test evidence.
- Updated README, examples, validation, and claims docs to describe the
  explicit Annex B rejection behavior.

## Claims

The project claims remain conservative:

- Encoder: independent, quality-gated, not byte-exact to ITU reference code or
  `bcg729`.
- Decoder: strict local decoder matches the private ITU Annex A final PCM
  oracle sample-for-sample in the current verifier run (`740800/740800`).
- Scope: G.729 Annex A, RTP payload type 18, `ptime=10` and `ptime=20`,
  `annexb=no`.
- Annex B: not supported; 2-byte SID/CNG frames are explicitly rejected.
- Not supported: G.729.1, G.729D, or G.729E.
- Certification: no ITU certification, endorsement, or encoder byte-exact
  conformance claim is made.
