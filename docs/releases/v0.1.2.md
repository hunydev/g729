# v0.1.2

Date: 2026-05-16
Module: `github.com/hunydev/g729`
Release tag: `v0.1.2`

## Summary

`v0.1.2` is a patch release after `v0.1.1`. It improves the product-default
Core encoder gain-codebook preselect center calculation while keeping the same
public codec scope and clean-room claims.

This release does not add new supported codec variants. The encoder remains an
independent, quality-gated implementation and does not claim byte-exact output
against ITU reference encoders or `bcg729`.

## Changes

- Improved Core encoder gain preselection by solving the unquantized gain center
  from full-correlation products before the existing integer GA/GB cost ranking.
- Kept `CoreFast` on the lower-cost fixed-point preselect path as an explicit
  performance trade-off profile.
- Refreshed FCB tree-search handoff oracle artifacts after the Core encoder
  update.
- Regenerated docs/demo audio outputs so the hosted samples match the current
  encoder.
- Updated the comparison web app to show the active full-compare candidates as a
  small lineage tree while preserving the metric table.

## Claims

The project claims remain unchanged from `v0.1.0` and `v0.1.1`:

- Encoder: independent, quality-gated, not byte-exact to ITU reference code or
  `bcg729`.
- Decoder: strict local decoder matches the private ITU Annex A final PCM
  oracle sample-for-sample in the current verifier run (`740800/740800`).
- Scope: G.729 Annex A, RTP payload type 18, `ptime=10` and `ptime=20`,
  `annexb=no`.
- Not supported: Annex B SID/CNG/DTX, G.729.1, G.729D, or G.729E.
- Certification: no ITU certification, endorsement, or encoder byte-exact
  conformance claim is made.
