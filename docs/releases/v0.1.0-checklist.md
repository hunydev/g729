from the exact commit that will be tagged `v0.1.0`.

## Distribution Audit

- `git status --short` is clean before tagging.
- `git ls-files` contains no private oracle CSV output, official ITU `.BIT` or
  `.PST` package, customer audio, third-party G.729 implementation source, or
  third-party G.729 binaries.
- `third-party/bcg729-blackbox/`, if present locally, remains ignored and
  untracked.
- `/home/exedev/g729_untracked/verifier-output`, if present locally, remains
  outside this repository.
- README, `IP_PROVENANCE.md`, `THIRD_PARTY_NOTICES.md`,
  `CLEANROOM_AUDIT.md`, `docs/claims-and-nonclaims.md`, and
  `docs/similarity-review.md` are consistent with the release claims.
