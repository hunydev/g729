# v0.1.0

Date: 2026-05-16
Module: `github.com/hunydev/g729`
Release tag: `v0.1.0`

## Summary

`v0.1.0` is the first official release of this clean-room, pure-Go,
MIT-licensed G.729A-compatible codec for RTP `G729/8000` `annexb=no` send
paths.

- Encoder: independent and quality-gated, not byte-exact to ITU reference code
  or `bcg729`.
- Decoder: strict local decoder matches the private ITU Annex A reference PCM
  oracle sample-for-sample in the current verifier run (`740800/740800` final
  PCM samples).
- Scope: G.729 Annex A, RTP payload type 18, `ptime=10` and `ptime=20`,
  `annexb=no`.
- Not supported: Annex B SID/CNG/DTX, G.729.1, G.729D, or G.729E.
- Certification: no ITU certification, endorsement, or encoder byte-exact
  conformance claim is made.

The next engineering focus is stronger encoder validation: reproducible
objective quality gates, broader sample coverage, long-running realtime load
tests, and black-box interoperability evidence without making encoder
byte-exact claims.
