# SEO/GEO Long-Running Goal

This document is the long-form goal for improving repository discoverability,
GitHub Pages SEO, and GEO/AI answer visibility for `github.com/hunydev/g729`
and <https://g729.huny.dev/>.

Use this file as the detailed instruction source for a Codex `/goal` session.
The short `/goal` prompt should refer back to this file.

## Objective

Improve how the project is understood and surfaced by:

- GitHub repository search and topic discovery.
- Web search engines such as Google and Bing.
- AI answer engines and retrieval systems that read public repository and site
  content.
- Human evaluators who need a quick, accurate summary of what this project is
  and is not.

The project should be discoverable for queries around:

- `G.729 codec Go`
- `G.729A codec`
- `pure Go G.729`
- `MIT G.729 codec`
- `clean-room G.729 codec`
- `G729/8000 annexb=no RTP`
- `VoIP G.729 RTP`
- `MRCP TTS IVR G.729`
- `Go audio codec`

Do not optimize by keyword stuffing or making stronger technical claims. The
goal is accurate machine-readable and human-readable positioning.

## Claim Boundary

All SEO/GEO work must preserve the repository's existing claims and
non-claims.

Allowed positioning:

- Clean-room implementation.
- Pure Go.
- MIT licensed.
- G.729A-compatible.
- Targets `G729/8000 annexb=no` RTP send paths.
- No cgo.
- No native codec runtime dependency.
- Decoder has private ITU Annex A final-PCM sample-exact validation evidence.
- Encoder is independent and quality-gated.

Forbidden positioning:

- Do not claim ITU certification.
- Do not claim ITU endorsement.
- Do not claim encoder byte-exact conformance to ITU, `bcg729`, FFmpeg, or any
  third-party encoder.
- Do not claim Annex B SID/CNG/DTX support.
- Do not claim `annexb=yes` support.
- Do not claim G.729.1 support.
- Do not claim G.729D or G.729E support.
- Do not claim that `llms.txt` or any AI-readable file is officially supported
  by major AI platforms.

If wording conflicts with `README.md`, `IP_PROVENANCE.md`,
`THIRD_PARTY_NOTICES.md`, `CLEANROOM_AUDIT.md`, `docs/validation.md`, or
`docs/claims-and-nonclaims.md`, fix the wording rather than expanding the
claim.

## Repository Discoverability

Review and improve the GitHub repository presentation.

### README

Ensure the top of `README.md` clearly states:

- Project name: `github.com/hunydev/g729`.
- What it is: clean-room, pure-Go, MIT-licensed G.729A-compatible codec.
- Target: `G729/8000 annexb=no` RTP send paths.
- Runtime dependency profile: no cgo, no native codec dependency.
- Encoder claim: independent, quality-gated, not byte-exact to ITU or
  `bcg729`.
- Decoder claim: strict path matches private ITU Annex A reference PCM
  sample-for-sample in the current verifier run.
- Unsupported features: Annex B, G.729.1, G.729D, G.729E.
- Website URL: <https://g729.huny.dev/>.
- pkg.go.dev URL if useful.

Prefer concise, high-signal text that can be used as a search snippet or AI
answer.

- Meta description is concise and accurate.
- Canonical URL points to `https://g729.huny.dev/`.
- Open Graph metadata exists.
- Twitter card metadata exists if appropriate.

- H1 clearly names the project.

JavaScript-rendered text.

## Sitemap and Robots

Add or update:

- `docs/sitemap.xml`
- `docs/robots.txt`

Rules:

- `robots.txt` should allow normal crawling.
- `robots.txt` should include a `Sitemap:` directive for
  `https://g729.huny.dev/sitemap.xml`.
- `sitemap.xml` should include canonical public pages only.
- Do not include private files, local artifacts, generated binary assets, or
  internal development notes.

## Validation Commands

Run at least:

```sh

```

If editing HTML/XML/TXT files, also run lightweight checks such as:

```sh

curl -fsS -I http://127.0.0.1:8001/
curl -fsS -I http://127.0.0.1:8001/robots.txt
```

Use available local tools for HTML/XML sanity if present, but do not add heavy
dependencies only for this task.
